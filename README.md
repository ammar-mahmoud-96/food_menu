# 🍽️ Food Menu

A Flutter application that allows users to explore food recipes from different countries around the world through an intuitive and visually appealing interface.

The project was built to demonstrate Flutter development concepts, including state management, navigation, responsive UI design, reusable widgets, and efficient data presentation.

---

## Features

- Browse recipes from multiple countries
- View detailed recipe information
- Categorized food items
- Responsive and user-friendly interface
- Fast and smooth navigation
- Reusable widget architecture
- Cross-platform support (Android, iOS, and Web)

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code

### Installation

Clone the repository:

```bash
git clone https://github.com/ammar-mahmoud-96/food_menu.git
```

Navigate to the project folder:

```bash
cd food_menu
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
